## Опросник Django

## Описание
Веб-приложение для блоггинга на базе официального tutorial Django 

### Клонирование и установка зависимостей
```cd djangotutorial```
```poetry install```

### Запуск приложения
```python manage.py runserver```

### Запуск тестов
```poetry run pytest -v```

### Запуск pre-commit
```poetry run pre-commit run --all-files```
